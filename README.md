# Examination Invigilation Protocol

A Moodle-compatible drag-and-drop activity for training teachers on examination invigilation duties.

## Features

- **Phase 1: Venue Preparation** - Drag-and-drop activity to categorize duties
- **Interactive Learning** - Drag duty cards into appropriate role columns
- **Immediate Feedback** - Invalid placements return to the card bank
- **Role Categories**:
  - Chief Invigilator
  - Invigilator
  - Both Roles

## Installation

1. Copy files to your Moodle installation
2. Upload as a Moodle activity
3. Configure duty cards and role assignments

## Files

- `index.html` - Main activity interface
- `styles.css` - Styling matching Moodle theme
- `script.js` - Drag-and-drop functionality
- `config.php` - Moodle configuration (if applicable)
